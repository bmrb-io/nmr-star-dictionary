# NMR-STAR Dictionary

**This branch is obsolete and is no longer updated.** Use the
[`nmr-star-production`](https://github.com/bmrb-io/nmr-star-dictionary/tree/nmr-star-production) branch, which
holds the current release: the combined dictionary file is
[`NMR-STAR/internal_106_distribution/NMR-STAR.dic`](https://github.com/bmrb-io/nmr-star-dictionary/blob/nmr-star-production/NMR-STAR/internal_106_distribution/NMR-STAR.dic),
and each release is tagged `nmr-star-v<version>`, e.g. `nmr-star-v3.2.14.0`.

The files here are a copy of the NMR-STAR v3.2.14.0 distribution, kept only for older versions of
[PyNMRSTAR](https://github.com/bmrb-io/PyNMRSTAR) (3.5.3 and earlier), which read `xlschem_ann.csv` from this
branch.

To report a bug or suggest new tags, please visit
[the github issues page](https://github.com/bmrb-io/nmr-star-dictionary/issues).
